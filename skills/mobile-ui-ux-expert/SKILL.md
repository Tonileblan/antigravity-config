# 📱 Mobile UI/UX Expert Guidelines

## Mobile Ergonomics
1. **Thumb Zone Architecture:** Essential controls placed in bottom 40% of the screen.
2. **Touch Target Sizing:** Minimum 44x44px (iOS) / 48x48dp (Android) clickable areas.
3. **Safe Areas:** Padding for notches, dynamic islands, and home indicator bars.
4. **Fluid Responsiveness:** Dynamic viewport units (`100dvh`), auto-collapsing navbars.
