# 🎨 UI/UX Expert Design Guidelines

## Core Principles
1. **Visual Hierarchy:** Distinct visual weights for primary actions, secondary interactions, and auxiliary data.
2. **Design Tokens & Dark Mode:** Consistent color semantics (Surface, Accent, Text Primary, Text Secondary, Borders, Glows).
3. **Micro-Interactions & State Changes:** Hover states, active transitions, skeletons, and loading feedback.
4. **Bento Grid & Modularity:** Clean 4-6 tile grids with varying aspect ratios for scannable data presentation.
5. **Accessibility & Contrast:** WCAG 2.1 AA compliance across all components.
