# 🛑 Accidental Data Loss Prevention

Before executing any operation that permanently alters, deletes, or truncates production data, repositories, or critical files:
1. Stop and verify target paths.
2. Request explicit user confirmation.
3. Provide a dry-run or backup plan before execution.
